
# OneLine｜一句话代办跨软件 AI Agent

让用户交代要办的事，由 Agent 管理中间流程，
在关键节点保留用户决定权。

## 项目解决什么问题
跨软件办公任务中，用户不仅需要重复点击，
还需要持续管理任务步骤、上下文和异常情况。

## 核心场景
整理发票 → 生成报销清单 → 准备邮件 → 用户确认 → 发送

## Agent 工作流
任务理解
→ 任务规划
→ 环境感知
→ GUI 定位
→ 操作执行
→ 结果验证
→ 必要时用户确认

## 核心产品设计
- 自主执行低风险操作
- 高风险节点用户确认
- Retry / Replan / Ask User
- 执行结果必须通过 Verifier 验证

## 验证框架
任务完成度 / 自主性 / 可控性 / 异常恢复能力 / 用户价值
